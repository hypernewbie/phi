Phi Themes for VS Code & Cursor
==============================

Official Phi color themes for Visual Studio Code and Cursor, matching all 22 Phi workspace accent palettes.

Installation:
- Copy the entire `vscode_themes` folder to your VS Code extensions directory:
  - macOS / Linux: `~/.vscode/extensions/hypernewbie.phi-themes-1.0.0`
  - Windows: `%USERPROFILE%\.vscode\extensions\hypernewbie.phi-themes-1.0.0`
  - Cursor: `~/.cursor/extensions/hypernewbie.phi-themes-1.0.0`

Usage:
1. Open VS Code / Cursor
2. Open Command Palette (Cmd+Shift+P / Ctrl+Shift+P)
3. Select "Preferences: Color Theme"
4. Choose any "Phi <Color>" theme (e.g. Phi Purple, Phi Cyan, Phi Emerald, etc.)
